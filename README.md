# 💇‍♀️ Sistema de Agendamento para Salão de Beleza

Aplicação web interativa desenvolvida em Python para gestão de marcações e administração de um salão de beleza.

## 🚀 O Problema que Resolve
Digitaliza e automatiza a agenda de negócios locais. O cliente consegue escolher serviços, datas e horários disponíveis de forma autónoma. O sistema bloqueia conflitos de horário automaticamente e oferece um painel de administração para o proprietário confirmar ou excluir atendimentos e visualizar estimativas de faturação.

## 💻 Tecnologias
* Python 3: Lógica de negócio e processamento de dados.
* Streamlit: Interface gráfica web (Frontend e Admin Dashboard).
* JSON: Base de dados local leve para armazenamento dos agendamentos.
